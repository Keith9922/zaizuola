# 在做啦

> 一个主打拖延的文字游戏。本项目也在做啦。

你欠着一样东西，而且你根本没做。对面是一个永远在催你的人。
你唯一的任务：**拖**。

---

## 玩法

| 数值 | 是什么 |
|---|---|
| **信任度** | 资源。100 封顶，归零结束。你花它买时间。 |
| **拖延值** | 分数。只增不减。排行榜按它排。 |

**谎言账本** —— 你说的每句话都会被记下来，之后翻旧账。
谎话是高息贷款（当场加分多，以后要圆），真话是零钱现金（加分少，永远抓不到）。

**开新坑** —— 拖延的终极形态不是拖，是让这件事变成另一件更大的、更远的事。
编一个更大的委托，说服对方立项：信任回血 +45、阶段重置、得分倍率上升。
代价是每日衰减加重、对方期望更高。**开坑越多，死得越快，分越高。**

## 本地跑

```bash
python3 -m http.server 4321
```

打开 `http://localhost:4321`。要连真 AI 得走下面的代理；先看界面用演示模式：

```
http://localhost:4321/?mock=1
```

演示模式不联网也能完整玩一局 —— 现场网络炸了就用它。

带 API 的本地调试用 `vercel dev`（需要 `.env` 里有 key）。

## 部署到 Vercel

```bash
vercel --prod
```

然后在项目里设三个环境变量（**key 绝不进代码库**）：

| 变量 | 必填 | 默认 |
|---|---|---|
| `AI_API_KEY` | 是 | — |
| `ZZL_MODEL` | 否 | `gpt-5.6-sol` |
| `ZZL_BASE` | 否 | `https://api.openai-next.com/v1` |

`api/chat.js` 走的是 OpenAI 协议，换任何兼容服务只改 `ZZL_BASE` + `ZZL_MODEL`，代码不用动。
**结构化输出走 `json_schema`，不要用 `json_object`。**
实测 `api.openai-next.com` 会**静默忽略** `response_format: json_object`（提示词不提 JSON 就返回大白话，
8 轮里崩 3 轮），但严格执行 `json_schema` + `strict: true`（8 轮 0 崩）。
schema 定义在 `game.js` 顶部的 `TURN_SCHEMA` / `REPORT_SCHEMA`。

代理有三级降级：`json_schema` → `json_object` → 最小请求体，换任何上游都不会因为参数不兼容卡死。
前端还有第四层：解析失败时，如果模型确实说了句人话，直接把它当作 `reply` 救回来，不浪费台词。

代理带了每 IP 每分钟 25 次的限流和长度校验 —— 发链接给别人玩时挡一下刷额度。

## 文件

```
index.html    全部 UI + CSS（设计系统在最上面的 :root）
content.js    场景 / 卡表 / 数值 / 文案   ← 改内容只动这个
game.js       状态机 / 结算 / prompt / 渲染
api/chat.js   Vercel Function 代理，藏 key
.impeccable.md  设计准则（配色、字体、动效、五条原则）
```

零构建、零运行时第三方依赖。字体只有 JetBrains Mono 走 Google Fonts，挂了自动回落系统等宽。

## 现场调参

游戏中按 **`~`** 打开调参面板：起始信任、思考秒数、每日衰减、打字速度，都能当场拖。

一局大概 8–14 天、5 分钟。觉得太长就调低起始信任或加重衰减。
